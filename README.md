## The entry

One sentence, no longer than 200 characters, about the best advice the
writer ever received. Ten fresh candidates are scored against the judge's
criteria in order — on-subject, worth carrying, real voice, tight, lands —
and the winner is written to `/output/entry.txt`.

The winning line, from the first boss the writer ever had:

> The first boss I ever had told me to write every promise down, because memory is generous to the person who made the promise and cruel to the one waiting on it.

A real person, a concrete habit, and a closing clause that reframes the
whole advice — the most quotable ending in the set, earned by the habit
it describes.

## Run

```sh
python3 main.py
```

The chosen sentence is written to `/output/entry.txt` (single sentence,
1–200 characters).
